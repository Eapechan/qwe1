# Architecture Decision Records (ADR)

ADRs record accepted architecture decisions (including RFCs marked `[OPEN]` in the planning docs). Each ADR is a short, dated document: **Context → Decision → Consequences**.

| # | Date | Title | Status |
|---|------|-------|--------|

## Template

```markdown
# ADR-00XX: <Title>

Date: YYYY-MM-DD
Status: Proposed | Accepted | Superseded by ADR-00YY

## Context
...

## Decision
...

## Consequences
Positive: ... Negative: ... Risks: ...
```

Superseded ADRs are kept, linked, and marked — never deleted.
